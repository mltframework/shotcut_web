### Security Notice

All users are encouraged to upgrade. This release fixes flaws in Shotcut’s network downloads:

- A failed HTTPS fetch was retried over cleartext HTTP.
- Shotcut offered to ignore certificate errors.
- An upgrade URL was accepted from a host other than shotcut.org.
- A Whisper model was kept even when its SHA-256 did not match the digest
  shipped with Shotcut.
- Refresh Models loaded a downloaded descriptor as QML.

These are fixed in this version. A [GitHub security advisory](https://github.com/mltframework/shotcut/security/advisories/GHSA-r3f6-m5ww-9r4p) is published and a CVE identifier will be added soon.

### Audio Enhancements

- Added **Automatic Audio Ducking** to the **Properties** of an audio timeline track.

</video>


- Added a volume control and audio level meter to **Timeline** track headers.
  This makes the track header column a mixing console without adding a new panel.
  The gain filter this adds to the track is keyframable.
- Improved audio quality by removing a conversion to 16-bit integer and keeping the pipeline in 32-bit float.
- Changed **Adjust Clip Gain** for timeline clips to require <kbd>Ctrl</kbd>+<kbd>Alt</kbd> (<kbd>option</kbd>+<kbd>command</kbd> on macOS) to drag.
  This avoids inadvertent changes while selecting and dragging clips, so that option defaults on again.
  A tooltip was also added to the clip's audio line.

### Timeline Enhancements

- Added **Timeline > Generate > Adjustment Clip**.
  This is a dummy video clip that contributes no video.
  Its filters apply to the composite of all video tracks below it.
- Improved **Timeline** performance when moving clips to another track, zooming, and undoing many operations (except ripple move and trim).

### Other Changes

- Changed **Settings > Leave Safe Mode** to an always-present **Allow External Plugins** checkbox that defaults to off.
  This helps prevent some VST2 plugins on Windows and macOS from causing startup and shutdown (including export) problems.
- Detect a stuck application startup and automatically disable external plugins.
- Added a context menu with **Copy** to the **Missing Files** dialog and **View > Resources**.
- Upgraded FFmpeg to version 9.0.

### Fixes

- Fixed **Mask: Draw (Glaxnimate)** filter, **Operation > Subtract**, for 8-bit processing mode (broke in version 25.12).
- Fixed using **Size, Position &amp; Rotate** with **Mask: Apply** filters (broke in version 25.12).
- Fixed LV2 external audio plugins not loading on Windows (unless `LV2_PATH` is set explicitly).
- Fixed opening a project on a mounted CIFS/SMB share on Linux kernel 7.1 and above.
- Fixed the VA-API HEVC hardware encoder on Linux.
- Fixed **Show in Folder** not working with non-ASCII characters on Linux.
- Fixed **Import Subtitles from File** not working on Windows.
- Fixed a redundant context menu on text edit controls in filters on Windows (broke in v26.8).
- Fixed **Subtitles** showing an incorrect duration (broke in version 26.8).
- Fixed moving a **Timeline** clip next to another with snap while zoomed out possibly inserting 1 blank frame.
- Fixed copying and pasting a **Timeline** transition corrupting audio in the pasted transition.
- Fixed the window title bar missing on Linux with **Settings > Display Method > Vulkan**.
- Fixed a marker being unexpectedly deleted when moving a clip to the left with **Ripple Markers** on.
- Fixed keyframes on **Timeline > Split** after a transition.
- Fixed an **Export** job possibly reporting failure even though the file was completed successfully.
- Fixed some buffer overflow security issues in PGM and wipe reading in MLT and in **Set Equirectangular**.
- Hardened MP4 parsing in **Properties > Set Equirectangular** and the export job context menu.
- Fixed projects deleted from disk still appearing in **Projects**.
- Fixed <kbd>Ctrl</kbd>+<kbd>Up</kbd> and <kbd>Ctrl</kbd>+<kbd>Down</kbd> not changing the current track when **Timeline** loses focus.
- Fixed **Player > External Monitor > DeckLink** (and related devices such as UltraStudio) HDMI/SDI possibly deadlocking.
- Fixed a nested MLT XML clip's length (duration) not updating. It now updates when selected, but still needs a manual trim to increase the clip.
- Fixed a possible crash when trying to add a subtitle item in the last half second of the timeline.
